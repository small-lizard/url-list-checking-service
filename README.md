
# url-list-checking-service
Это фронтенд сервиса по проверке URL. Бэкенд можно найти здесь ([repo](https://github.com/small-lizard/url-list-checking-service-backend)).

## Стек

**Frontend**  React, TypeScript, Zustand, Tailwind

**Deployment:** Vercel

## Запуск
  
Для запуска локально:

1. Скопировать репозиторий

```bash
git clone https://github.com/small-lizard/url-list-checking-service
cd url-list-checking-service
```

2. Установить зависимости

```bash
npm install
```

3. Запустить

```bash
npm run env:dev
```

5. Запустить

```bash
npm run dev
```
